# App Icons

This folder contains icon variants for the launcher and desktop integration.

## Included files

- `motorola_bootloader_icon.svg` — scalable vector icon used by the desktop launcher
- `motorola_bootloader_icon_128.png` — generated 128x128 PNG placeholder
- `motorola_bootloader_icon_64.png` — generated 64x64 PNG placeholder
- `motorola_bootloader_icon_32.png` — generated 32x32 PNG placeholder
